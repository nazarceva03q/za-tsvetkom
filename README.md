Сайт цветочной мастерской в Перми. Отдельный проект, не сайт «Аура цветов».

**Единая документация: [docs/project/README.md](docs/project/README.md).**

- [Состояние](docs/project/STATUS.md), [решения](docs/project/DECISIONS.md), [архитектура](docs/project/ARCHITECTURE.md), [эксплуатация](docs/project/OPERATIONS.md).
- [Короткая инструкция закрытой панели](docs/owner/PANEL-QUICKSTART.md).
- Полная история, инструкция РКН и все недостающие данные сохранены локально в проекте; их пути указаны в документации. Закрытые материалы не публикуются в открытом GitHub.

Локальный просмотр: `node server.cjs`, затем http://localhost:8091.

Витрина и закрытая панель подготовлены; запуск реальных заявок отложен. Публикация документов не включает формы. Правило обязательного обновления документации закреплено в [AGENTS.md](AGENTS.md).
