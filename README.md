# За цветком

Сайт цветочной мастерской в Перми. Самостоятельный проект, отдельно от сайта «Аура цветов».

## Просмотр

Установите Node.js и выполните `node server.cjs`. Откройте http://localhost:8091.

## Каталог

21 товар с описаниями и ценами магазина. Данные находятся в `products-data.js`, фотографии в `assets/products/`. Соответствие и число снимков указаны в `PHOTO-MAPPING.json`.

Все 21 товар представлены фотографиями. В последнем наборе 44 файла, из них один повторяется: в каталог добавлены 43 уникальных снимка. Ракурсы одного товара объединены в галерею. Общий снимок двух корзин оставлен дополнительным ракурсом; основное фото показывает одну корзину.

Выпускной: ежегодный отсчёт до 20 мая по времени Перми, без отображения даты на карточке. Бесплатная доставка 101 розы по городу отражена в каталоге и условиях доставки.

## Перед запуском

Формы пока не отправляют заявки, наличие подтверждает флорист. Требуются реальные товары шаров, ссылки MAX/ВК, контактная почта и подключение обработки заявок. Документы в `legal.html` являются проектом для согласования.
