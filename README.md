# За цветком

Сайт цветочной мастерской в Перми. Самостоятельный проект, отдельно от сайта «Аура цветов».

## Просмотр

Установите Node.js и выполните `node server.cjs`. Откройте http://localhost:8091.

## Каталог

21 товар с описаниями и ценами магазина. Данные находятся в `products-data.js`, фотографии в `assets/products/`. Соответствие и число снимков указаны в `PHOTO-MAPPING.json`.

Из ожидаемых 48 фотографий доступны 36. Не хватает: розы и хризантемы – 1; сирень – 2; Тиффани – 1; композиция с российскими розами – 4; корзина 101 роза – 4. У двух последних товаров временно показано место для фотографии. Другие фотографии не подставляются.

Выпускной: ежегодный отсчёт до 20 мая по времени Перми, без отображения даты на карточке. Бесплатная доставка 101 розы по городу отражена в каталоге и условиях доставки.

## Перед запуском

Формы пока не отправляют заявки, наличие подтверждает флорист. Требуются оставшиеся фотографии, реальные товары шаров, ссылки MAX/ВК, контактная почта и подключение обработки заявок. Документы в `legal.html` являются проектом для согласования.
