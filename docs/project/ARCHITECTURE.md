# Архитектура

`index.html`/`app.js` и CSS — витрина, каталог, корзина, формы. `checkout.js` и `checkout-client.js` — проверка и идемпотентная отправка, без сохранения контактов в служебном локальном состоянии. `catalog-sync.js` и `catalog-live.js` — отображение актуального каталога.

`api/v1/` — публичные шлюзы PHP. `backend/orders/lib/` — закрытые приём, MySQL-хранилище, очередь, авторизация панели, решения о хранении, удаление и фильтр восстановления. На сервере этот код и заполненная конфигурация размещаются вне web-root. `backend/orders/migrations/` — последовательные миграции, не повторять вслепую.

`bot/src/vkWebhook.js` — аутентификация, нормализация и дедупликация VK; `bot.js`/`admin.js` — сценарии; `catalogClient.js` — работа с серверным каталогом; `siteRelay.js` — минимальное уведомление; `requestPanel.js` — ссылки панели; `store.js`/`objectStorage.js` — хранилище с условными записями.

`legal.html`, `consent.html`, `returns.html` — публичные юридические страницы. Общий источник условий возврата предотвращает расхождение сроков. Закрытый реестр удаления, SQL, заполненные соглашения и инфраструктурные реквизиты в публичном репозитории не хранятся.

Размещение, идентификаторы, процедуры восстановления, инцидентов и доступов — в полной локальной документации проекта.
