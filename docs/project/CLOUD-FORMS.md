# Облачные формы: пауза

09.11.2026: после повторной ошибки пользователь остановил настройку до восстановления хостинга. На клиенте intakePaused=true: новые обращения не отправляются, корзина и ключ неизвестной попытки сохраняются. Серверное выключение рекомендовано, но не подтверждено. Облачная схема описана в обновлённых документах для последующего возобновления. Worker подтвердил только пустой обход без ошибок; фактическая доставка новых заявок и удаление старых сообщений VK не подтверждены. Перед возобновлением сверить серверные флаги, исходный ключ/сохранение и снять клиентскую паузу по указанию пользователя. Эти изменения не публикуются на REG и не затрагивают main.
