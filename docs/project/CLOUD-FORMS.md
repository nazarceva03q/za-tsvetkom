# Подготовка облачных форм

08.11.2026: временный сайт подготовлен к отдельному облачному обработчику. Приём выключен серверным INTAKE_ENABLED=false. Успех означает сохранение, не подтверждённую доставку VK. Публичные юридические страницы не обновлялись в этом изменении; перед включением нужна их согласованная публикация. REG-публикация и основная ветка не меняются. Изменены только обработчик формы, исключение для формы вопроса, клиент отправки и подключение скриптов. Сохранены повтор с тем же ключом и корзина при неизвестном результате.
