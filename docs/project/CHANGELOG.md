# История публичного проекта

## 09.11.2026

- Завершено согласование публичных страниц с приостановленным приёмом: условная облачная схема, собственные сроки рабочих/технических записей, исправленные ссылки на временном сайте. Обновлена точка продолжения и сохранён запрет новых отправок без очистки корзины/pending. Изменения не возобновляют приём и не публикуют файлы на REG.

## 08.11.2026

- По указанию пользователя настройка приостановлена до восстановления хостинга. Документы приведены к состоянию паузы и условной схеме последующего облачного приёма. Клиент блокирует новые отправки, сохраняя корзину и ключ неизвестного результата; серверные флаги из локального окружения не менялись. Обновлены инструкции возобновления.

- Исправлен адрес облачного обработчика по фактической ссылке функции. При обновлении адреса сохраняется ключ неподтверждённой попытки и корзина; новый идентификатор автоматически не создаётся.

- Подготовлена редакция согласия и политики для облачного хранения и передачи содержания в закрытую беседу VK; версия клиента согласована с документами. Указан запрос удаления сообщения, без обещания гарантированного результата внешнего сервиса. Приём остаётся выключенным до установки и публикации.

- Локально подготовлен клиент облачного приёма: настраиваемый HTTPS endpoint, отдельное состояние повторов, ключ с ограниченным сроком первого использования, сохранение корзины при неизвестном результате. Обращение одновременно к облаку и PHP не выполняется. Публикация и включение реального приёма пока не подтверждены.

## 05.11.2026

- Уточнены условия обработки данных при доставке привлечёнными курьерами через сервис Яндекса. Полученные от владельца организационные сведения сохранены в закрытой документации. Запрошенная схема двух ботов ещё не введена в эксплуатацию.

## 28.10.2026

- В политике и условиях оплаты название конкретного платёжного сервиса заменено общими формулировками: оплата по внешней ссылке после согласования заказа, необходимые данные для оплаты и чеков. Подключение сервиса не утверждается как состоявшийся факт. Обновлены локальные исходники и копии документов.

- Подготовлены окончательные публичные юридические страницы редакции 27.10.2026, отдельное согласие/возврат, ссылки футера и согласованные уточнения витрины.
- Добавлен ограниченный режим публикации документов, не меняющий backend или запуск.
- Создана единая публичная карта и полная локальная документация. Постоянное правило обновления закреплено в AGENTS.md.
- Проверены 66 сценариев клиента/бота, 11 сценариев публикации, три страницы на 390/1280 px.
- Полный набор остаётся локально: первоначальный push 191 файлов отклонён автоматической проверкой риска публикации внутренних/персональных сведений. Для GitHub подготовлен уменьшенный набор; внутренние материалы не должны попадать в его историю.

Публикация успешно выполнена отдельным job и независимо проверена HTTP; подробности в PUBLICATION-2026-10-28.md. Приём реальных заявок не включался. Детальная история, юридические вопросы, сведения о доступах и настройках — в закрытой локальной документации, не в публичном GitHub.
