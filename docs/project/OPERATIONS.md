# Проверки и публикация

- `node --test tests/orders-client.cjs tests/site-relay.cjs tests/vk-bot-simplified.cjs tests/admin-flow.cjs tests/bot-storage-retention.cjs` — клиент, бот и relay.
- `python tests/publish-storefront.py` и `python tests/publish-legal.py` — разрешённые файлы, целевая папка и защита публикации.
- `node tests/legal-browser.cjs` — юридические страницы на 390/1280 px; требуется браузерное окружение, указанное в сценарии.
- `git diff --check` и проверка состава/секретов перед commit.

`scripts/publish-legal.py` выбирает ровно legal.html, consent.html, returns.html, app.js и index.html. Использует FTPS с проверкой сертификата и сверяет удалённую папку с HTTPS-сайтом до записи. Не загружает backend, SQL или конфигурацию и не включает формы. После выкладки сверяет файлы по HTTP.

Полное размещение сервера/бота, миграции и восстановление выполняются только по актуальной локальной инструкции. Не использовать публичную примерную конфигурацию вместо заполненной. Не восстанавливать старую базу непосредственно на рабочем сайте.

При изменении сохранять документацию и результаты проверок. Пароли, токены, ключи реестров и копии данных не помещать в Git или сообщения.
