# Свободная цена и общая сетка карточек — 20.10.2026

Подготовлено локально. На REG.RU/Яндекс автоматически не установлено.

Бот принимает непустой текст цены без отдельного ограничения длины в коде
поля. Действуют ограничения сообщений VK и размера запросов сервиса.
Примеры: `1000 ₽`, `от 1000 руб.`, `1000–2000 ₽`, `Товар под заказ`.
Текст хранится в `priceLabel`, для каждой фотографии оформления — в
`photoPriceLabels`. Точная положительная числовая цена сохраняет числовое
поле для корзины и фильтров. Диапазон/описание получает `price: null`,
не превращается в 10002000 или ноль. Для него на витрине — «Уточнить цену»,
для бизнес-оформления сохраняется «Обсудить оформление». Числовые фильтры
не включают товары без точной цены при заданном диапазоне; без фильтра
видны все товары. Новые поля не требуют миграции MySQL или переимпорта seed.

Карточки всех типов выравниваются по каждому фактическому ряду: одинаковый
формат фотографии 3:4, общие уровни названия, ссылки, пояснения, цены и
кнопки. Миниатюра заполняется без полей (cover); полное фото остаётся в
просмотрщике. Высоты пересчитываются после обновления каталога, фильтрации,
загрузки шрифтов и изменения размера окна, включая новые товары бота.
Длинная цена переносится целиком, текст не обрезается.

## Установка: важно соблюдать порядок

1. Сохранить резервную копию текущих файлов. Заменить только
   `/private-orders/lib/Catalog.php` файлом `backend/orders/lib/Catalog.php`.
   Проверить `/opt/php/8.3/bin/php -l "$HOME/private-orders/lib/Catalog.php"`.
   Конфигурацию/секреты/существующий каталог не менять.
2. В корень рабочего сайта `/www/xn----ctbjb9aqim7a5cq.online/` загрузить
   `app.js`, `refinement.js`, `catalog-live.js`, `catalog-sync.js`,
   `compact-cards.js`, `compact-cards.css`; затем `index.html` с новыми
   версиями ссылок. Важно загружать в www, а не в одноимённую папку рядом.
3. Только после обновления API и витрины загрузить новый
   `bot/yandex-deploy-simplified.zip` в Яндекс. Проверить наличие
   `src/price.js`, сохранить все существующие переменные окружения.
   Node.js 22, `index.handler`, остальные настройки прежние.
4. На тестовом товаре проверить все варианты текста цены, затем точную цену.
   Проверить карточки в смешанном разделе шаров, на телефоне и компьютере;
   цену отдельного фото оформления, редактирование и снятие «Хита».
   Тестовые товары удалить после проверки. Приём заявок/уведомления
   автоматически не включать.

Старый загрузчик каталога не поддерживает null-цену: новый бот нельзя
активировать раньше нового API/JS витрины. Безопасный откат после ввода
текстовых цен требует совместимой версии загрузчика и API.
