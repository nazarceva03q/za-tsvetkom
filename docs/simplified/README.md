# Упрощённые заявки: REG.RU → Яндекс → VK

Начальное состояние и принятые решения зафиксированы до изменений в PLAN.md.
Порядок будущей настройки: SETUP.md. Ничего не опубликовано, SQL на рабочей базе не выполнялся.

## Результат
Все существующие формы отправляют заявку в PHP REG.RU. Без фотографии, без проверки по каталогу Яндекса и без подтверждения суммы.
База сохраняет имя, телефон, способ связи, тему/тип формы, пожелания, дату, доставку при необходимости, количество/бюджет и текстовый состав корзины. Для вопроса товар не требуется.
Заявка, позиции и очередь записываются одной транзакцией. На сайте успех только после commit. При ошибке корзина и поля открытой формы сохраняются. Сохранение контактов после перезагрузки браузера не добавлено.
Яндекс/VK недоступны — заявка остаётся в REG.RU и панели. Если сам REG.RU недоступен, сайт не обещает сохранение.

## Панель Екатерины
Публичный адрес после отдельной выкладки: /owner/orders.php. До неё этот адрес не является работающим входом.
Отдельный логин/пароль, случайные сессии с хешем в MySQL, ограничение попыток, Secure/HttpOnly cookies, CSRF, HTTPS и no-store.
Список последних заявок по 50 на страницу, фильтр типов, дата по Перми, полная карточка и звонок по телефону. Нет публичного получения по номеру.
Суммы новых заявок NULL, не фиктивный ноль. Условия согласуются с Екатериной.
Панель содержит контакты, адрес и комментарии; уведомление VK — только минимальную карточку без этих данных.
Смена пароля не отзывает старые сессии автоматически: экстренное закрытие и отзыв требуют отдельной операции. Автоочистка персональных данных не реализована; сроки/процедуру необходимо согласовать.

## Бот
src/products.js, src/objectStorage.js и src/vkApi.js не изменены: работа каталога, цен, фото, категорий, остатков и «Хита» остаётся прежней.
Бот не переписан на PHP и не перенесён с Яндекса. Действия администраторов продолжают использовать прежние сценарии.
Покупательские автоматические диалоги недоступны; обычные сообщения сообщества остаются для ответа владелицы.
Административная кнопка заявок ведёт в закрытую панель. Старые JSON-заявки не удаляются.
Новый siteRelay.js принимает только подтверждённые уведомления REG.RU с секретом заголовка. Старый публичный приём phone закрыт кодом 410, чтобы не обходить MySQL.
Квитанция доставки хранится приватно в Yandex Object Storage, без контактов и текста уведомления.
Новый ZIP: bot/yandex-deploy-simplified.zip. Старый yandex-deploy.zip не заменён.
